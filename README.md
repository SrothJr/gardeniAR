**gardeniAR** is an innovative gardening assistant that leverages Augmented Reality (AR) to revolutionize your gardening experience. Seamlessly blending digital management with the physical world, our platform offers interactive tools to monitor plant health, manage tasks, and connect with a vibrant community of fellow gardeners.

</div>

## Core Features

- **Augmented Reality Interface:** Visualize plant growth, ideal placement, and health metrics in your own garden using AR.
- **Task Management Checklist:** Keep your gardening on track with an intuitive checklist system for watering, pruning, fertilizing, and more.
- **Community Forum:** Engage with a passionate community of gardeners. Share your progress, exchange tips, and seek advice on our integrated forum.
- **Multi-Platform Sync:** Access your garden from anywhere with our synchronized web and mobile applications.

## Technology Stack

gardeniAR is built on a modern, robust, and type-safe technology stack:

- **Languages:** JavaScript (83.7%), TypeScript (11.0%), CSS, HTML
- **Frontend (Web):** A responsive and intuitive web interface for comprehensive garden management.
- **Mobile App:** A dedicated mobile application featuring powerful AR integrations.
- **Backend:** A Node.js-powered server that manages user data, community forums, and API services.

## Project Structure

This project is organized as a monorepo to streamline development across platforms:

```
/
├── backend/      # Server-side API and database logic
├── frontend/     # Web application source code
├── mobile/       # Mobile application source code (AR features)
```

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- [Node.js](https://nodejs.org/) (Latest LTS version recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/SrothJr/gardeniAR.git
    ```
2.  **Navigate to a module** (e.g., `backend`):
    ```sh
    cd gardeniAR/backend
    ```
3.  **Install dependencies:**
    ```sh
    npm install
    ```
4.  **Configure Environment:** Follow the specific `README.md` instructions located within the `backend`, `frontend`, and `mobile` directories to configure your environment variables and start the application.
